## 8. Ландмайны (на них спотыкались)

1. **Стейл-зелёное с чужого коммита** — главный урок серии. Зелень считается только по
   актуальной голове: `gh pr checks <N>` + сверка headSha рана с HEAD ветки. gitleaks «pass»
   однажды относился к коммиту, которого в PR уже не было.
2. **Греп по диффу ловит собственные отчёты** — `.claude/reports/*.md` цитируют проверки
   (`skip`, `xfail`, `noqa`...). Проверки честности диффа всегда с ограничением
   `-- packages/` (или другим кодовым путём).
3. **Стенд для гейтов API — контейнеры podman**, не `.venv`: `biotact-api` (python:3.11-slim,
   код смонтирован в `/api` из текущего дерева) + `biotact-parity` (postgres:17). Сначала
   `podman ps` — оба Up; команда: `podman exec biotact-api sh -c "cd /api && <команда>"`.
   Bind-mount `/pipcache` указывает в scratchpad старой сессии — при `podman start` каталог
   создать заново.
4. **Мутационные правки прод-файлов блокирует codex-wall.sh**, пока `workflow-state.json.state`
   не `coding`/`reviewing` — держит обе роли. На `planning` эмпирику проверяй скриптом МИМО
   репо (`podman exec ... cat > /tmp/probe.py`), не Edit/Write в `src/`.
5. **`npx tsc --noEmit` на solution-tsconfig ничего не проверяет** — нужен `tsc -b`
   (память `tsc-noemit-solution-tsconfig-noop`; в этом репо уже вычищено всюду — PR #120).
6. **Мутация может совпасть с оригиналом по смыслу** — проверяй, что она МЕНЯЕТ наблюдаемое
   поведение (прогон + разница в выводе), не только текст.
7. **Мутационная сюита может быть слабой ровно в «главных» тестах** — перепроверяй руками
   именно те, что автор называет главными. Ревьюер-2 гонял 4 из 6 мутаций экранирования
   собственной постановкой — все краснеют где надо; M6 заодно уронила соседний тест (пин
   `len(sent)==2`) — разбирайся в причине каждого лишнего красного, не списывай.
8. **`git checkout -- <file>` сносит незакоммиченное** — перед откатом мутации убедись, что
   дерево чистое (память `feedback-sabotage-rollback-checkout`).
9. **Отчёты/спеки едут в кодовых коммитах** — обычай репо, не находка; скоуп смотри по
   кодовой части диффа.
10. **Гейт, объявленный зелёным по прошлому состоянию — не гейт.** Проверка Л5: метка
    `find src tests -newer <метка>` пуста ПОСЛЕ прогона.
