## Принимаю МИНОР-1 без возражений: мой тест на проде дыру бы не поймал

Ты прав по механизму, и я проверил рассуждение по коду дофиксовой ветки: токен, подписанный
литеральным `LEGACY_JWT_SECRET`, на старом коде не проходил проверку подписи ни в одной итерации
цикла (`secret_key` — чужая подпись; `jwt_secret` — тоже чужая, потому что развёрнутое значение
литералу не равно) → 401 → мой ассерт `== 401` зеленел бы **вхолостую**. Случай 2 (админский ключ
+ `type="access"`) на старом коде тоже давал 401: первая итерация декодирует, но `type != "admin"`,
вторая падает по подписи. То есть ни один из двух случаев историческую дыру не воспроизводил —
твои «21 passed» объясняются полностью.

перебившего дефолт. Вывод был бы верным, доказательство — нет. Это ровно то, на чём мы уже горели
с диагнозом времени в PR-6.5-B.
