## Сделано — по пунктам спеки

**API (2 read-эндпоинта, ноль новых мутаций):**
- `GET /admin/lottery/current` — `eligible_tickets` считается той же `eligible_clean_tickets`, что
  штампует заморозка (Р-3); тираж — последний по номеру **любого** статуса, включая отменённый
  (Р-2); победители — из строк билетов (страница переживает перезагрузку).
- `GET /admin/lottery/{id}/print` — номера по возрастанию, last-4 с ведущими нулями (`0042`),
  полный `telegram_id` не уезжает; **отменённому — 409** (уточнение Гейта-1 №1: штампы сняты,
  пустая печать = порча снаружи; список отменённого — журнал выгрузки).
- Оба под `require_loyalty_enabled` + `require_admin`, как соседи. Граница из пяти гейтов на
  каждый (dark-404 · 401 · 403 обычным · 403 админ-типизированным не-админу · позитивный контроль).

**Админка (4 состояния + печатная страница):**
- `ConfirmDialog` + необязательный `confirmValue` (Р-1): без пропа поведение прежнее, закреплено
  рендер-тестом (уточнение №2).
- Страница `/loyalty/draw`: заморозка с вводом пост-фильтрового числа · живой тираж (отпечаток,
  печать, дата, победители, отмена) · результат · отменённый (тексты отмены и отпечатка рядом —
  Р-6; журнал через авторизованный клиент, не голой ссылкой).
- При `eligible = 0` кнопка заблокирована с подписью (уточнение №3); ошибка чтения — по паттерну
  дашборда (уточнение №4); ошибки мутаций — текстом сервера (`detail` несёт число/номер);
  копирование с запасным выделенным полем при отсутствии буфера (Р-6).
- Печатная `/loyalty/draw/print/:drawId` — без навигации, `@media print`, PDF не генерируется.
  Два lazy-маршрута, ссылка «Провести розыгрыш» на дашборде.

недопечатанное значение не переживает переоткрытие по построению. Коммит `223af27`, 48/48 после.

## Отклонения от спеки

1. **Тексты Р-6 «рядом» стоят на состоянии `cancelled`** (отпечаток + отмена), а не на
   `committed`: текст отмены до отмены не существует; интент «не потерять текст отмены» исполнен —
   он стоит рядом с текстом отпечатка там, где отмена публикуется. На `committed` — текст отпечатка.
2. **Маршрут печати — path-параметр** `/loyalty/draw/print/:drawId` (спека писала
   `/loyalty/draw/print` без параметра) — печать открывается и с состояния `drawn`, где id нужен
   явно; query-string хуже ложится в router.
3. Скрин-файл `__scratch_print_html.test.tsx` для снятия HTML создан, прогнан и **удалён** —
   в диффе его нет.
