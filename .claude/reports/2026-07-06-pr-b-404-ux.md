# Отчёт: PR-B — 404 UX (отличить «тёмное» от «код не найден»)

Спека: `.claude/specs/2026-07-06-pr-b-404-ux.md` · Подход: **Design 1** (фазовый тег), одобрен Капитаном.

## Сделано — по пунктам спеки
- **`useActivation.ts`**: добавлен класс `ProgramDarkError` (обёртка над `ApiError` через нативный
  `Error` `cause`, без parameter property — совместимо с `erasableSyntaxOnly`). `mutationFn` ловит
  ошибку `consent('qr')`: `ApiError.status === 404` → бросает `ProgramDarkError` (тёмная программа);
  всё остальное (503/401/сеть) и любой 404 от `activate` — пробрасывает как есть.
- **`ActivationPage.tsx`**: `errorContent` теперь принимает `Error`. `ProgramDarkError` →
  `activation.error.dark` («скоро»), без ретрая. Иначе по статусу: **404 → `invalidCode`** (живой
  неизвестный код), 409 → `invalidCode`, 503 → `unavailable`+retry, прочее → generic+retry.
  Ветка `isError` вызывает `errorContent(activation.error)` (единый путь рендера).
- **`ActivationPage.test.tsx`**: существующий 404-тест переименован → «consent 404 (dark) → скоро,
  activate не вызван». **Добавлен** тест: consent 200 + activate 404 → «Код недействителен…», без
  «скоро», без «Повторить».

## Ключевой инвариант (почему без backend)
Мутация: `consent('qr')` → потом `activate(code)`. `consent` даёт 404 ТОЛЬКО когда программа тёмная
(`require_loyalty_enabled` бьёт до логики; `record_consent` при живой программе не 404 никогда).
Значит 404 от `activate` в живой программе = только неизвестный код. Тёмный гейт на бэке остаётся
голым 404 — непробиваемость не тронута; фронтовое сообщение на пробиваемость не влияет.

## Не сделано / отложено
- Backend не изменён (контракт статусов прежний) — по спеке.
- Отдельного UX «программа на паузе» нет — это отдельная фича, не защитный 404.

  (я, Инженер, их не гоняю; отдаю мех-гейты зелёными + этот отчёт).

## Security-relevant surface (для Ревьюера)
- Тёмный гейт `require_loyalty_enabled` (router.py) НЕ изменён — 404 остаётся голым/непробиваемым.
- Новый класс ошибки чисто клиентский; никакого нового сетевого поведения/эндпоинта/тела ответа.
- 409 (чужой код) по-прежнему generic — без утечки личности.
