## Сделано — по пунктам спеки
- **Роут `/activate` + `ActivationPage`** (lazy, как остальные страницы). `ROUTES.ACTIVATE`.
- **Редирект входа (решение A):** `App` → `HomeOrActivate` на `ROUTES.HOME` — при `?code=<code>` на корне `<Navigate replace>` на `/activate?code=<encoded>`; без кода — обычный `HomePage`. (Бот открывает корень `?code=`; `start_param` для web_app-кнопок не доставляется — проверено `keyboards/inline.py:95`.)
- **Поток:** чекбокс согласия (обязателен, кнопка «Активировать» `disabled` пока не отмечен) → `useActivation` мутация: `POST /loyalty/consent {source:'qr'}` → `POST /qr/activate {code}` (последовательно; consent гейтит activate) → на успехе инвалидирует `['loyalty','me']`.
- **Результат ветвится по `status`** (МИНОР Гейта-1): `activated` → «Код активирован! Начислено N баллов» (+welcome при `welcomeBonus>0`, +флип «Друг» при `tier==='biotact_friend' && friendBonus>0`, +баланс); `already_activated` → «Код уже активирован» — **без** «Начислено» (исторический эхо не подаётся как свежее начисление); показывает текущий баланс.
- **Маппинг ошибок по `ApiError.status`:** 404 → нейтраль «программа скоро» (тёмный, не probeable), 409 → «код недействителен/использован», 503 → «попробуйте позже» + ретрай; сеть/timeout/прочее → общая + ретрай. Ретрай только на transient (503/сеть); 404/409 — без ретрая. Нет кода в URL → нейтральный экран.
- **API-адаптер:** `loyaltyApi.consent(source)` + `activate(code)` (snake→camel, DTO-интерфейсы). **Типы** `RegistrationSource`/`ConsentResult`/`ActivationStatus`/`ActivationResult`.
- **i18n:** секция `activation.*` в `ru.json` **и** `uz.json` (структурный паритет — enforced `tsc` через `Translations = typeof ru`).
- Код нигде не логируется; `LoyaltyCard` не тронут.

## Отклонения от плана и почему
1. **`fireEvent` вместо `userEvent`** — user-event не зависимость проекта; следую конвенции репо (см. «Замечено»). Тест-стандарт предпочитает userEvent, но добавление зависимости = решение Капитана/ops, вне скоупа PR.
2. **`useActivation` = единая мутация consent→activate** (не два раздельных хука) — проще для страницы, атомарная последовательность, consent гейтит activate одним `await`; инвалидация в `onSuccess`.
3. Результат рисуется из `ActivateResponse` + «В профиль»-кнопка (карту не встраивал — `LoyaltyCard` на профиле сам подтянет свежий `/me` после инвалидации; scope-минимум).
