## Цель
Пользователь, открывший мини-апп **без** `?code=` (обычный вход, не по QR), может вступить в Biotact Club: обязательный чекбокс согласия → `POST /loyalty/consent {source:'direct'}` (без баллов) → профиль показывает карту лояльности. Не-член видит CTA «Присоединиться»; член — карту. Тёмный по факту backend-404 до PR-4.5.

## Контекст (проверено чтением кода)
- `HomeOrActivate` (App.tsx) редиректит на `/activate` ТОЛЬКО при `?code=`; без кода — обычный `HomePage`. Экран активации без кода не показывается (уже так с PR-4.3). ✓
- `GET /loyalty/me` (`get_loyalty_summary`, service.py:70-109) возвращает newbie-дефолты и для `user is None`, и для `profile is None` — **сигнала членства нет** (ни в сервисе, ни в `LoyaltySummaryResponse`). Это и есть гэп, закрываемый ниже.
- `customer_profile`-строка создаётся как результат `joined` (PR-4.2: инсертер профиля пишет `joined` — и через consent, и через activate). ⇒ «есть профиль» = каноничное «участник».
- `loyaltyApi.consent(source)` уже есть (PR-4.3); `useLoyalty` (`['loyalty','me']`, retry:false); `LoyaltyCard` (self-contained, `if(!data) return null`); ProfilePage:140 — единственный `<LoyaltyCard/>`, вокруг ничего не завязано.
- `activation.consentLabel` (ru+uz) — легальный текст согласия data_processing (переиспользуем).

## Скоуп PR — что входит

### Backend (API) — закрытие membership-гэпа (A-уточнённый)
- `LoyaltySummary` dataclass (service.py): +`is_member: bool`.
- `get_loyalty_summary`: `is_member` вычисляется из **уже выполняемого** `SELECT customer_profile` — `is_member = profile is not None` (для `user is None` и `profile is None` → `False`; профиль есть → `True`). **Ноль новых round-trip'ов, ноль миграций, НЕ трогаем `Consent`** (профиль = каноничное «участник»; `Consent.granted`/ревокацию НЕ проектируем — rule #6).
- `LoyaltySummaryResponse` (schemas.py): +`is_member: bool = Field(...)`.
- `router.get_loyalty_me`: прокинуть `is_member=summary.is_member`.

### Frontend
- `types/index.ts`: `LoyaltySummary` +`isMember: boolean`.

- `hooks/useJoin.ts` (нов.): `useMutation` → `loyaltyApi.consent('direct')`, `onSuccess` → инвалидация `['loyalty','me']`. Экспорт в `hooks/index.ts`.

## Отклонение от стадийной спеки (зафиксировано явно)
Стадийная спека §4.4a называла 4.4a «front-only (front + api/loyalty.ts + pytest)». **Расширяем на backend** (одно поле `is_member` в уже-вычисляемом `/loyalty/me`-ответе): Discovery вскрыл реальный технический гэп — `/me` не отдаёт сигнала членства, без него свап CTA-vs-карта и корректный показ карты на go-live невозможны. Это закрытие гэпа минимальной ценой (ноль запросов/миграций), не изобретение нового. Одобрено Капитаном на Гейт-1 (A-уточнённый).
