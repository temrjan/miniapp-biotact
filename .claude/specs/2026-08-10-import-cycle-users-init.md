## Репродукция — есть, воспроизводится одной командой

```
$ python -c "import src.loyalty.lottery"
ImportError: cannot import name 'CurrentUser' from partially initialized module
             src.auth.dependencies (most likely due to a circular import)
```

Цепочка: `lottery` → `src.auth.service` → `src/auth/__init__` → `auth.dependencies` →
`src.users.models` → `src/users/__init__` → **`src.users.router`** → снова `auth.dependencies`,
ещё не собранный.

**Ожидаемое поведение:** любой модуль `src.*` импортируется в чистом интерпретаторе.
**Фактическое:** 27 из 81 (33%) падают. Полный список — в `/check`-разборе ниже по тексту отчёта
`2026-08-10-unsurveyed-with-balance-filter-gate2.md` не дублирую; перемеряется одной командой.

## Скоуп PR

**Заголовок:** `fix: модули импортируются в одиночку — снят пакетный цикл users↔auth`

**Входит:**
1. `src/users/__init__.py` — снять импорт роутера (решение по `__all__` — см. В-2).
2. Обход по утверждению: `models_registry.py`, `expire_stale_orders.py`,
   `test_cli_scripts_start.py` — привести три описания в соответствие с новым состоянием.
3. Регрессионный тест: **каждый** модуль `src.*` стартует в чистом интерпретаторе (по образцу
   существующего `test_cli_scripts_start.py` — тот же приём с подпроцессом, та же причина).

**НЕ входит:**
- «Расшивание цикла в роутерах», как предлагает комментарий в `models_registry` — если дешёвая
  правка закрывает симптом полностью, большая перестройка становится отдельным решением (В-1).
- Удаление ставшего ненужным `import src.models_registry` из `expire_stale_orders.py` (В-3).
- Порядок в `_MODEL_MODULES` не переставляю: он перестаёт быть несущим, но перестановка — лишний
  риск в этом же круге.

## Критерии приёмки
- `python -c "import <любой из 27>"` — проходит; обход по всем 81 модулю даёт 0 падений.
- Регрессионный тест падает, если вернуть удалённую строку (доказать мутацией, а не заявить).
- Гейты как в CI: `ruff check src/ tests/ scripts/` · `ruff format --check src/` ·
  `mypy src/ --strict` · `pytest tests/` — зелёные **после последней правки**.
- Ни одного места, где написано «цикл резолвится порядком загрузки», не осталось в силе.

## Тест-план
1. **Красная фаза:** новый страж написан → прогон на текущем коде → **падает** (27 модулей).
2. Правка → страж зелёный.
3. **Мутация:** вернуть строку в `__init__` → страж обязан упасть именно на ней.
4. Полная сюита + старт приложения (`main` импортируется) + `alembic check` — порядок в
   `models_registry` был несущим для миграций, это надо доказать прогоном, а не рассуждением.

## Риски
- **Скрытый потребитель переэкспорта**, которого не поймал grep (динамический доступ). Снимается
  полной сюитой и стартом приложения; цена — приложение не поднимется на первом же прогоне, до прода.
- **`alembic`** зависит от `models_registry`; если порядок был несущим и для него — увидим на
  `alembic check` в CI (джоба «Migration parity» существует).
