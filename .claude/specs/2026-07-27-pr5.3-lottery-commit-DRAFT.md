## Решения, принятые до паузы (требуют ратификации на Гейте-1)

1. **Хеш — побайтовый контракт.** Одна строка на билет, сортировка по `ticket_number` ASC,
   формат строки `{ticket_number};{user_id};{source}`, разделитель строк `\n` (LF), без финального
   переноса, кодировка UTF-8, целые — десятичные без ведущих нулей, `source` — значение енума
   в нижнем регистре. Хеш = SHA-256 от UTF-8-байтов, hex в нижнем регистре.
   Обоснование: номер обязан быть связан с участником внутри хеша, иначе после публикации номера
   можно переставить. Публикуем внутренний `user_id` (не телефон/имя) — внешняя сверка возможна,
   персональные данные не раскрываются.
2. **Повторный `commit_draw` — ОТКЛОНЯЕТСЯ (409), не идемпотентен.** Снимок — юридический
   артефакт; «молча вернуть существующий» скрывает операционную ошибку. Гонку решает
   `SELECT … FOR UPDATE` по строке розыгрыша + проверка `status` внутри транзакции; мутация
   (снять `.with_for_update()`) обязана краснить тест.
3. **Возраст побеждает галку.** Если `age` известен — он решает: `age >= 18` → участвует,
   `age < 18` → НЕ участвует, даже с галкой. Галка говорит только когда `age` не заполнен.
   ⚠️ Это уточнение формулы эпик-спеки («adult = is_adult ИЛИ age>=18») — нужна ратификация.
   Позиция Ревьюера совпадает (строгое чтение). Факт-переключатель: юрист скажет, что галка —
   юридически значащее заявление, а сохранённый возраст неавторитетен.
4. **Заморозка — свойство снимка, не пересчёт на чтении.** После `commit_draw` ни снятие галки,
   ни потеря «Друга», ни новая активация не меняют проведённый розыгрыш. Тест: commit → изменить
   профиль → снимок и хеш не сдвинулись.
5. **Авторизация админ-эндпоинта — `require_admin`** (`analytics/router.py:21`: `type="admin"` +
   поход в БД + проверка `User.is_admin`), **НЕ `verify_admin_jwt`**. Заморозка розыгрыша не
   должна висеть на зависимости, которая роль не проверяет. Решение остаётся верным и после PR-S.
6. **Время:** period-арифметика через `datetime.now(UTC)` + явная конверсия в `Asia/Tashkent`
   для границ месяца и отображения; наивный `utcnow()` запрещён. Тест-план обязан включать
   `prod_timezone` и прогон под не-UTC поясом — зелёное на UTC-раннере про Ташкент не говорит.
